# Centro de orquestación agéntica (demo)

Versión de demostración con datos de ejemplo, publicada para que el equipo vea el panel: facturación frente al objetivo de 100.000 EUR, pedidos y facturas, tiendas y enlaces verificados, agentes, conectores y plan de 6 meses.

La app real corre en local (Desktop/repos/orquestacion-agentica) y usa datos internos.
